# 🎬 Movie Review Platform

A full-stack web application that allows users to explore movies, view details, and access personalized recommendations using real-time data.

---

## 🌐 Live Demo

👉 https:https://movie-review-frontend-swart.vercel.app/

---

## 📌 Overview

The Movie Review Platform enables users to browse movies, view ratings, and receive personalized recommendations.
It integrates external APIs to fetch real-time movie data and provides a dynamic and responsive user experience.

---

## ✨ Key Features

* 🎥 Browse and explore movies
* ⭐ View ratings and reviews
* 🔍 Search functionality
* 🤖 Personalized movie recommendations
* 🌐 Real-time data using TMDB API
* 💻 Responsive and modern UI

---

## ⚙️ How It Works

1. Fetches real-time movie data from TMDB API
2. Displays movie details and ratings
3. Generates personalized recommendations
4. Handles user interactions dynamically
